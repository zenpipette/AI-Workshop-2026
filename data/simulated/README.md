# SIMULATED DATA — placeholder README (full version pending from brief 05)

> **SIMULATED DATA.** Values in this folder were generated from summary statistics published in the
> INSPIRE study papers (McGuire 2017 AJCN; Ruiz 2017 Front Immunol; Lackey 2019 Front Nutr; Lane 2019
> AJPA; McGuire 2021 Front Immunol; Pace 2021 Microorganisms; Caffé 2023 AJHB). **No individual-level
> INSPIRE data were used.** Individual values are synthetic; only group-level patterns resemble the
> published results. This is not the original study data.

Status 2026-10-10: data files were produced by `R/02_simulate_dyads.R` but have **not yet been
validated** against the published statistics. The validation script and the full README are the next
step (see `PROGRESS.md`). Treat these files as a draft until `validation_report.md` exists.
